## สิ่งที่มีอยู่แล้ว และหลักฐานที่แต่ละตัวแสดง

| ฟีเจอร์ | ทำงานเองโดยไม่ต้องกดไหม | หลักฐานที่แสดง |
|---|---|---|
| ข้อเสนอแนะประจำวัน (PR/โอน) | ไม่ทำเอง กดแล้วได้**ร่าง** | ใช้วันละ, มี, **ค้างรับ, ระยะส่งที่ใช้คิด, วันสำรอง, ของที่มีพอกี่วัน** (เพิ่มใน F1), ใบค้าง, คลังมีแค่ |
| แนะนำสั่งซื้อในปฏิทิน | ไม่ทำเอง ปุ่มเปิดฟอร์ม PR | แนะนำ, คงเหลือ, กำลังมา, ใช้เฉลี่ย, หมดในกี่วัน, **ระยะส่งที่ใช้คิด** (เพิ่ม), สูตร |
| ความเสี่ยงส่งช้า | ไม่ทำเอง (แจ้งเตือนอย่างเดียว) | คะแนน /100 + เหตุผลแต่ละข้อพร้อมคะแนน |
| ของหมดก่อนของมา | ไม่ทำเอง | วันที่คาดว่าหมด, ช่องว่างกี่วัน/กี่หน่วย, เหตุผล |
| ปรับสต๊อก/ของเสียจำนวนมาก | ไม่ทำเอง (แจ้งเตือน) | จำนวน, เหตุผล, มูลค่า, **% ของยอดก่อนปรับ และเกินเกณฑ์อะไร** (เพิ่ม) |
| อ่านบิลด้วย AI (OCR) | ไม่ทำเอง เติมฟอร์มให้คนยืนยัน | แสดงบรรทัดที่อ่านได้แต่ไม่ได้เติมพร้อมเหตุผล |
| ผลงานผู้ขาย | ไม่ทำเอง | อัตรา + "x จาก n" |

**สิ่งที่ระบบเขียนเองโดยไม่ต้องกด (เดิม ไม่เปลี่ยน):**
- งานนับสต๊อกตามตารางที่เปิดไว้
- การแจ้งเตือน
- การลบแจ้งเตือนที่หมดอายุ และข้อความเก่ากว่า 90 วัน
- heartbeat ของ cron

ระบบ**ไม่สร้าง** PR/PO/โอน **ไม่ปรับสต๊อก** และ**ไม่ส่ง LINE เอง**
