## ข้อ 2 — การเคลื่อนไหว

| เหตุการณ์ | ใช้หน้าไหน | บันทึกเป็น |
|---|---|---|
| ครัวผลิตเสร็จ → เข้าคลัง | รับสินค้าเข้า → **"รับจากครัว (ผลิตเอง)"** | `receive`, `supplierName` = "ครัว (ผลิตเอง)", ไม่มีเลขบิล/วันที่บิล/รูปบิล |
| ส่ง WIP ไปสาขา | ระบบส่งสินค้า (Logistics) หรือ เบิก/โอนสาขา → โอน | `transfer` เหมือนของอื่น |
| สาขาทำเอง | รับจากครัว โดยเลือก "รับเข้าที่" = สาขานั้น | `receive` ที่สาขา |
| หน้าร้านใช้ | เบิก/โอนสาขา → เบิกใช้ | `consume` |

- โหมดครัว: ช่องค้นหาแสดงเฉพาะสินค้าหมวด WIP ที่ยังใช้งาน, ไม่ตรวจเลขบิลซ้ำ, มีช่องหมายเหตุ (รอบผลิต/ผู้ผลิต)
- โค้ด: `src/pages/receive/receipt.ts` (`Mode` += `'kitchen'`, `KITCHEN_SUPPLIER`, `kitchenProblem`), `src/pages/Receive.tsx`, `src/pages/receive/ReceiptReview.tsx`
- เดินใน demo แล้ว: เพิ่ม 24 รายการ → รับจากครัว Pizza Dough 12" 2 ถาด → RC ได้ 24 ลูก เข้าคลังหลัก ผู้ขาย "ครัว (ผลิตเอง)" ไม่มีเลขบิล

## ข้อ 3 — ผลิตตามสูตร (โครง ยังไม่ทำ)

ตอนนี้รับ WIP เข้าแล้ว **วัตถุดิบไม่ลดเอง** — ครัวต้องเบิกวัตถุดิบออกเอง (เบิกใช้ที่ครัว) ข้อ 3 คือให้ระบบตัดให้

**ต่อยอดจากของที่มีบน demo แล้ว**: `Recipe` / `RecipeLine` + `src/services/recipes.ts` (Automation Plan P3 — สูตรต่อเมนู POS) โครงเดียวกันใช้กับสูตร WIP ได้

1. **สูตร WIP**: `Recipe` เพิ่ม `kind: 'menu' | 'wip'` และ `yieldProductId` + `yieldQty` (เช่น แป้ง 12" 1 ถาด = แป้ง 5 KG, ยีสต์ …) — หรือ collection แยก `wipRecipes` ถ้าไม่อยากแตะสูตรเมนู (ตัดสินตอนออกแบบ; ระวังงบ 1,000 expressions ของ rules)
2. **โหมดรับจากครัว**: ถ้าสินค้ามีสูตร แสดง "จะตัดวัตถุดิบ: …" ในหน้าตรวจสอบ แล้วลงใน transaction เดียวกัน: `receive` WIP + `consume` วัตถุดิบที่คลังเดียวกัน อ้างเลขเอกสารเดียวกัน (ใช้ `planAdjust`/`consume` เดิม ไม่ต้องมีชนิด movement ใหม่)
3. **วัตถุดิบไม่พอ**: เตือนแต่ไม่บล็อก (ของจริงมักคีย์ช้ากว่าของ) — หรือบล็อก ให้เจ้าของเลือก
4. **ต้นทุน WIP**: มูลค่าต่อหน่วย = ผลรวมต้นทุนวัตถุดิบตามสูตร ÷ yield (ตอนนี้ WIP ไม่มีราคา มูลค่าสต๊อกจึงนับเป็น 0)
5. สิ่งที่ต้องถามเจ้าของก่อนเริ่ม: สูตรจริงของแต่ละ WIP (ใครให้ข้อมูล), ผลิตที่คลังไหน (ครัวสุขุมวิท 23 = คลังหลัก?), ของเสียระหว่างผลิตนับยังไง

ก่อนขึ้นของจริงต้อง deploy rules ของสูตร (ถ้าเพิ่มฟิลด์) — ถามเจ้าของก่อนทุกครั้ง
