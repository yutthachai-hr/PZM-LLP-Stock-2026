# SC-008 — ดูว่าเดือนนี้ใช้อะไรไปเยอะ

## สิ่งที่ตั้งใจจะทำ

อยากรู้ว่าเดือนนี้ใช้ของอะไรไปเยอะที่สุด และเทียบกับเดือนก่อนแล้วเพิ่มขึ้นไหม

## เกิดอะไรขึ้นจริง

ต้องบอกก่อนว่ารอบนี้ทดสอบบนเดโมที่มีข้อมูลจริงแค่วันเดียว (วันนี้) ทั้งระบบ ไม่ใช่ข้อมูลเป็นเดือน ๆ อย่างที่ร้านจริงจะมี เพราะฉะนั้นตัวเลขที่ได้จะบางมาก แต่ที่จะเล่าต่อไปนี้เป็นเรื่องว่า "หาทางไปถึงคำตอบได้ง่ายแค่ไหน" เป็นหลัก

กดเข้าเมนู "รายงาน" ที่แถบซ้าย หน้าที่เปิดมาเป็นแท็บ "ภาพรวม" เห็นช่องวันที่ "ตั้งแต่วันที่ 09/10/2026 ถึงวันที่ 09/23/2026" ขึ้นมาเป็นค่าเริ่มต้นโดยไม่มีป้ายบอกว่านี่คือช่วงอะไร (ไม่ใช่ "เดือนนี้" เพราะเดือนนี้เริ่ม 1 ก.ย.) เลยไม่แน่ใจว่าตัวเลขที่เห็นอยู่ตรงหน้าคือของช่วงไหนกันแน่

ลองกดแท็บ "การเคลื่อนไหว" ดูก่อน คิดว่าน่าจะมีอันดับของที่เบิกเยอะสุด แต่ที่เจอเป็นตารางรายการเบิก-รับของทีละบรรทัด ไม่ได้สรุปว่าอะไรเยอะสุด เลยกดย้อนกลับไปแท็บ "ภาพรวม" ตามเดิม

พอเลื่อนลงมาดูในหน้า "ภาพรวม" เจอกล่อง "ข้อมูลเชิงลึก" ทางขวา มีบรรทัดเขียนว่า "สินค้าที่เบิกใช้มากที่สุด: MOZZARELLA WHOLE MILK 2.72*8 (FOODGALLERY) เบิกเป็น 100% ของการเบิกใช้ทั้งหมด" อันนี้ตอบคำถามแรกได้ทันที

ทีนี้พยายามหาว่า "เทียบเดือนก่อนแล้วเพิ่มขึ้นไหม" — ในหน้านี้ไม่มีตัวเลขเทียบเดือนก่อนให้เห็นเลย เลยต้องแก้ช่องวันที่เองให้เป็นวันที่ 1-23 กันยายน (เดือนนี้เต็ม ๆ) ก่อน ตัวเลขเหมือนเดิม (เพราะข้อมูลมีแค่วันเดียว) จากนั้นแก้ช่องวันที่อีกรอบเป็น 1-31 สิงหาคม เพื่อดูเดือนที่แล้ว ผลคือ "รับสินค้าเข้า 0 รายการ, เบิกใช้ 0 รายการ" และกราฟโดนัทขึ้นข้อความ "ไม่มีการเบิกใช้ช่วงนี้" ชัดเจนดี แต่กล่อง "ข้อมูลเชิงลึก" กลับไม่มีบรรทัด "สินค้าที่เบิกใช้มากที่สุด" โผล่มาเลย (หายไปเฉย ๆ ไม่มีข้อความอธิบายว่าเพราะไม่มีข้อมูล)

สรุปแล้วตอบได้ว่า: ของที่เบิกเยอะสุดเดือนนี้คือ MOZZARELLA WHOLE MILK 2.72*8 (FOODGALLERY) และเทียบกับเดือนก่อน (สิงหาคม) ที่ไม่มีการเบิกเลย ก็ถือว่า "เพิ่มขึ้น" จากศูนย์ — แต่ต้องไปนั่งสลับวันที่เองสองรอบ ระบบไม่ได้สรุปให้ว่าเพิ่มหรือลดกี่เปอร์เซ็นต์

## จุดที่ติด

### 1. ช่วงวันที่เริ่มต้นของหน้ารายงานไม่ใช่ "เดือนนี้" และไม่มีป้ายบอกว่าคือช่วงอะไร

- **คาดว่าจะเป็น:** เปิดหน้ารายงานมาน่าจะเห็นข้อมูล "เดือนนี้" เป็นค่าเริ่มต้น หรืออย่างน้อยมีคำอธิบายกำกับว่าช่วงวันที่ที่โชว์อยู่คือช่วงไหน (เช่น "14 วันล่าสุด")
- **เกิดจริง:** ช่องวันที่ขึ้นมาเป็น 10-23 ก.ย. ลอย ๆ ไม่มีคำอธิบายว่าทำไมเลือกช่วงนี้ ต้องมานั่งคำนวณเองว่าตรงกับ "เดือนนี้" ไหม (ไม่ตรง เพราะเดือนเริ่ม 1 ก.ย.)
- **หน้า:** /reports
- **ภาพ:** แท็บ "ภาพรวม" ช่องกรอกวันที่สองช่อง "ตั้งแต่วันที่" แสดง 09/10/2026 และ "ถึงวันที่" แสดง 09/23/2026 ไม่มีข้อความกำกับความหมายของช่วงนี้ ด้านล่างเป็นการ์ดตัวเลข "รับสินค้าเข้า (รวม) 2 รายการ" "เบิกใช้ (รวม) 1 รายการ"

### 2. ไม่มีฟังก์ชันเทียบกับเดือนก่อนให้ในตัว ต้องสลับวันที่เองแล้วจำตัวเลขมาเทียบ

- **คาดว่าจะเป็น:** เมื่อโจทย์ชัดว่าอยากรู้ "เทียบเดือนก่อนแล้วเพิ่มหรือลด" คิดว่าหน้ารายงานน่าจะมีตัวเลขเทียบให้เลย เช่น เปอร์เซ็นต์เพิ่ม/ลดข้างชื่อของที่เบิกเยอะสุด
- **เกิดจริง:** ไม่มีจุดไหนในหน้านี้เทียบเดือนต่อเดือนให้ ต้องแก้ช่องวันที่เป็นเดือนนี้เต็มเดือนดูครั้งหนึ่ง แล้วแก้เป็นเดือนที่แล้วดูอีกครั้งหนึ่ง แล้วจำตัวเลขมาเทียบเอง
- **หน้า:** /reports
- **ภาพ:** หน้า "ภาพรวม" หลังแก้วันที่เป็น 08/01/2026–08/31/2026 การ์ดขึ้น "รับสินค้าเข้า (รวม) 0 รายการ" "เบิกใช้ (รวม) 0 รายการ" ไม่มีตัวเลข % เทียบกับช่วงก่อนหน้าที่ใดในหน้าเลย

### 3. กล่อง "ข้อมูลเชิงลึก" ไม่บอกอะไรเลยเมื่อไม่มีของถูกเบิกในช่วงนั้น ทั้งที่กราฟข้าง ๆ ยังอธิบายได้

- **คาดว่าจะเป็น:** ถ้าช่วงที่เลือกไม่มีการเบิกใช้เลย กล่อง "ข้อมูลเชิงลึก" ควรมีข้อความบอกตรง ๆ ว่า "ไม่มีการเบิกใช้ในช่วงนี้" เหมือนที่กราฟโดนัทข้าง ๆ ทำ
- **เกิดจริง:** พอเปลี่ยนช่วงเป็นเดือนสิงหาคม (ซึ่งไม่มีข้อมูล) บรรทัด "สินค้าที่เบิกใช้มากที่สุด" หายไปเฉย ๆ เหลือแค่บรรทัด "ไม่มีสินค้าต่ำกว่าขั้นต่ำ" ซึ่งเป็นคนละเรื่องกัน ถ้าไม่ได้สังเกตกราฟโดนัทข้าง ๆ ที่บอกไว้ชัดเจนกว่า อาจเข้าใจผิดว่าระบบโหลดข้อมูลไม่ครบ
- **หน้า:** /reports
- **ภาพ:** แท็บ "ภาพรวม" ช่วงวันที่ 08/01/2026–08/31/2026 กล่อง "ข้อมูลเชิงลึก" ทางขวาแสดงแค่ไอคอนติ๊กเขียว "ไม่มีสินค้าต่ำกว่าขั้นต่ำ" บรรทัดเดียว ไม่มีบรรทัดเรื่องของที่เบิกเยอะสุดเลย

## ข้อสังเกตอื่น

- จุดที่ทำได้ดี: ตัวเลขในการ์ดและกราฟอัปเดตทันทีที่แก้ช่องวันที่ ไม่ต้องกดปุ่มรีเฟรชเพิ่ม สะดวกดี
- กราฟโดนัท "การเบิกใช้ตามประเภทสินค้า" ตอนไม่มีข้อมูล (เดือนสิงหาคม) ขึ้นข้อความ "ไม่มีการเบิกใช้ช่วงนี้" ตรงกลางกราฟ ชัดเจน ไม่ทำให้เข้าใจผิดว่าระบบพัง — เป็นตัวอย่างการทำ empty state ที่ดี ตรงข้ามกับปัญหาข้อ 3 ที่กล่องข้าง ๆ ทำแบบเดียวกันไม่ได้
- กล่อง "ข้อมูลเชิงลึก" ตอนเดือนกันยายน (มีข้อมูล) เขียนชื่อของและเปอร์เซ็นต์ชัดเจนดี อ่านแล้วเข้าใจทันทีไม่ต้องตีความ
