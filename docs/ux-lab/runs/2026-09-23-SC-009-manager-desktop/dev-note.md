## ข้อ 2 ทำซ้ำไม่ได้ และรู้ว่าอะไรน่าจะทำให้เข้าใจผิด

ทดลองตรง ๆ: เลื่อนหน้าปฏิทินลง 342 พิกเซล แล้วอ่านป้ายเดือนซ้ำ — **ยังเป็น "ตุลาคม 2569" เหมือนเดิม**
ไม่มี `<select>` สำหรับเดือนในหน้านี้ (มีแต่ตัวกรองประเภท/สถานะ/ระดับ/คลัง/ผู้ขาย)
การเลื่อนจอจึงเปลี่ยนเดือนไม่ได้

**สิ่งที่น่าจะเกิดขึ้นจริง**: ปฏิทินอยู่ที่เดือนตุลาคมด้วยเหตุอื่น (น่าจะกดปุ่มเปลี่ยนเดือนเองโดยไม่รู้ตัว)
และงานวันที่ **30 กันยายน** ไปปรากฏใน**แถวแรกของตารางเดือนตุลาคม** ซึ่งเป็นช่องวันท้ายเดือนก่อนที่ปฏิทินทุกอัน
วาดไว้เป็นปกติ agent เห็นงานของตัวเองอยู่ในตารางที่หัวเขียนว่า "ตุลาคม" แล้วสรุปว่าเดือนเปลี่ยนเอง

บันทึกไว้เผื่อเจอซ้ำ: ถ้ามี run อื่นรายงานว่าเดือนเปลี่ยนเองอีก ให้กลับมาดูใหม่ว่าอะไรเป็นตัวสั่งให้เปลี่ยน
ครั้งเดียวและทำซ้ำไม่ได้ ยังไม่พอจะตั้งเป็นเรื่อง

## ข้อ 1 ยืนยันแล้ว และเจอความไม่สม่ำเสมอเพิ่ม

แผงรายละเอียดของงานที่บันทึกไว้แสดง `คลัง/สาขา: ไม่ระบุ` และ `ผู้รับผิดชอบ: ทุกคน` ตามที่ agent เล่า

ที่ agent ไม่ได้สังเกต: **ตัวกรองของหน้าเดียวกันใช้คำว่า "ทุกคลัง"** ไม่ใช่ "ไม่ระบุ"
สองคำนี้อยู่บนหน้าจอเดียวกันห่างกันไม่กี่เซนติเมตร ผู้ใช้ย่อมเดาว่าเป็นของอย่างเดียวกัน
ทั้งที่ความหมายต่างกัน — เพิ่มข้อนี้เข้าไปใน Issue เอง

## ที่ทำได้ดีและควรเก็บไว้

run นี้เร็วที่สุดเท่าที่มีมา (90 วินาที 7 actions ไม่มีทางตัน ไม่มี error)
สองอย่างที่ agent ชมและตรวจแล้วจริง:

- ประเภทงานถูกตั้งเป็น "นับสต๊อก" ให้อัตโนมัติเมื่อเปิดฟอร์มจากบริบทนั้น
- ติ๊ก "ทุกคน" แล้วขึ้นข้อความ "มอบหมายให้ทุกคน" ทันที และช่องชื่อคนถูกปิดไปเอง

ข้อหลังคือรูปแบบที่ `UX-0015` บอกให้เอาไปใช้กับช่องคลัง/สาขา — **ของที่ถูกอยู่แล้วอยู่ในฟอร์มเดียวกัน**
