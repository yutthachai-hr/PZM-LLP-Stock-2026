# SC-006 — ดูว่าอะไรใกล้หมด แล้วตั้งให้เตือนล่วงหน้า

## สิ่งที่ตั้งใจจะทำ

อยากรู้ว่าตอนนี้ของอะไรใกล้หมดบ้าง แล้วตั้งจุดสั่งซื้อของชีสไว้ที่ 5 กิโล จะได้เตือนก่อน

## เกิดอะไรขึ้นจริง

ระบบที่เข้าไปนี่เป็นเดโมที่มีของและประวัติอยู่แล้วตั้งแต่ก่อนหน้า (ไม่ได้เริ่มจากศูนย์) — เห็นมีรายการรับของ/เบิก/โอน/ปรับสต๊อกของเมื่อ 15:xx อยู่ในหน้าแรกด้วย ส่วน "ชีส" ที่โจทย์บอกให้ใช้ ในระบบเป็นภาษาอังกฤษล้วน ลองไล่ดูแล้วตัวที่มีของจริง ๆ อยู่คือ **MOZZARELLA WHOLE MILK 2.72*8 (FOODGALLERY)** รหัส CHS-01-01-001 มีของ 7 KG ที่คลังหลัก เลยใช้ตัวนี้เป็น "ชีส" ตามที่โจทย์บอก

เข้าระบบมาที่หน้าแรก (ภาพรวม) ก่อน เห็นการ์ด "สินค้าคงเหลือน้อย" บอกว่า 0 รายการ และช่องด้านล่างเขียนว่า "ไม่มีรายการที่ต่ำกว่าขั้นต่ำ" — จดไว้ว่านี่คือคำตอบเรื่องของใกล้หมด ตอนนี้ระบบบอกว่าไม่มีเลยสักตัว (จดไว้ก่อนที่จะไปแก้อะไร)

จากนั้นกดเข้า "สินค้าคงคลัง" ทางเมนูซ้าย (ลองกดคำว่า "สินค้าคงคลัง" ตรงข้อความบนแถบเมนูก่อน กดแล้วหน้าไม่ขยับไปไหน เลยลองกดที่ไอคอนแถวเดียวกันแทนถึงเข้าไปได้) เข้ามาเจอหน้าตารางสินค้าใหญ่มาก (288 รายการ) เลยกดแท็บหมวดหมู่ "Cheese & Dairy" (ตอนแรกมือเผลอไปโดนแท็บ Meat & Seafood ก่อน) พอเข้าหมวด Cheese & Dairy แล้วเห็นของเกือบทุกตัวสถานะ "หมดสต๊อก" มีแค่ตัวมอสซาเรลล่าตัวเดียวที่เป็น "ปกติ" — ใช้ช่องค้นหาพิมพ์ "mozzarella whole milk" ก็เจอตัวที่ต้องการทันที

กดที่ชื่อสินค้าเพื่อเปิดไปตั้งจุดสั่งซื้อ ระบบเปิดหน้าต่าง "แก้ไขสินค้า" ขึ้นมา เห็นช่อง "สต๊อกขั้นต่ำ (แจ้งเตือนเมื่อถึง)" ซึ่งน่าจะเป็นช่องที่ต้องการพอดี ตอนนั้นค่าเป็น 0 — ลบให้หมดแล้วพิมพ์ 5 เข้าไป เห็นในช่องเปลี่ยนเป็น 5 จริง แต่พอมองหาปุ่ม "บันทึก" กลับไม่เจอ ในหน้าต่างนี้มีแค่ปุ่ม "ปิด" (ทั้งไอคอน X มุมบนขวา และปุ่ม "ปิด" ล่างสุด) กับปุ่ม "บันทึกราคาใหม่" ซึ่งเป็นของช่องราคาต้นทุนคนละส่วนกัน

ลองกด "ปิด" (ไอคอน X) ดูก่อน แล้วเปิดสินค้าตัวเดิมใหม่เพื่อเช็ค — ช่องจุดสั่งซื้อกลับไปเป็น 0 เหมือนเดิม แปลว่าค่าที่พิมพ์หายไป ลองใหม่อีกรอบ คราวนี้พิมพ์ 5 แล้วกด Enter ก่อนปิด จากนั้นกดปุ่ม "ปิด" ตัวจริง (ปุ่มล่างสุด ไม่ใช่ไอคอน X) — เช็คอีกที ก็ยังเป็น 0 เหมือนเดิม ลองเปิดจากเมนู "..." (ตัวเลือกเพิ่มเติม) ที่ท้ายแถวตารางดูอีกทาง กับลองสลับเป็นมุมมองการ์ดแล้วกดที่การ์ดดูอีกทาง ก็พาไปที่หน้าต่างเดียวกันทั้งหมด ไม่มีปุ่มบันทึกให้กดเลยสักทาง

ลองมาสี่ทางแล้วไม่มีทางไหนใช้ได้ ถ้าเป็นงานจริงตอนนี้คงต้องไปบอกหัวหน้าด้วยปากแทนว่า "ตั้งจุดสั่งซื้อของชีสไม่ได้ กดบันทึกไม่เจอ" — เลยถือว่าเลิกตรงนี้

## จุดที่ติด

### 1. หน้าต่าง "แก้ไขสินค้า" ให้พิมพ์จุดสั่งซื้อได้ แต่ไม่มีปุ่มบันทึกค่านั้น

- **คาดว่าจะเป็น:** พิมพ์เลขในช่อง "สต๊อกขั้นต่ำ (แจ้งเตือนเมื่อถึง)" แล้วน่าจะมีปุ่ม "บันทึก" ให้กดเพื่อยืนยัน เหมือนช่องราคาต้นทุนที่มีปุ่ม "บันทึกราคาใหม่" ของตัวเอง
- **เกิดจริง:** ในหน้าต่างทั้งหมดมีแค่ปุ่ม "ปิด" (ทั้งไอคอน X และปุ่มข้อความ "ปิด") กับปุ่ม "บันทึกราคาใหม่" ที่ใช้ได้เฉพาะช่องราคาต้นทุนเท่านั้น ไม่มีปุ่มบันทึกสำหรับชื่อ/หมวดหมู่/หน่วย/จุดสั่งซื้อ/ผู้ขายเลย พิมพ์ 5 ในช่องแล้วปิดหน้าต่างด้วยวิธีไหนก็ตาม (ไอคอน X หรือปุ่ม "ปิด") ค่าที่พิมพ์หายกลับไปเป็น 0 ทุกครั้ง ลองเปิดจากทั้งชื่อสินค้า, เมนู "ตัวเลือกเพิ่มเติม" ท้ายแถว, และจากมุมมองการ์ด ก็เจอหน้าต่างแบบเดียวกันหมด ไม่มีทางบันทึกค่านี้ได้เลย ระบบก็ไม่ได้ขึ้นข้อความเตือนอะไรว่าบันทึกไม่สำเร็จ — แค่เงียบแล้วค่าหายไปเฉย ๆ
- **หน้า:** /products (หน้าต่าง "แก้ไขสินค้า" ที่เปิดทับอยู่)
- **ภาพ:** หน้าต่างป็อปอัป "แก้ไขสินค้า" มีช่องชื่อสินค้า, SKU, บาร์โค้ด, หมวดหมู่, หน่วยนับ, ช่อง "สต๊อกขั้นต่ำ (แจ้งเตือนเมื่อถึง)" ที่พิมพ์ "5" ได้จริง, ช่องผู้ขาย, ส่วนต้นทุน/ราคาที่มีปุ่ม "บันทึกราคาใหม่" แยกต่างหาก, และท้ายสุดของหน้าต่างมีแค่ปุ่ม "ปิด" สีเทาปุ่มเดียว ไม่มีปุ่มสีแดง/ปุ่มยืนยันอื่นให้เห็นเลย

## ข้อสังเกตอื่น

- ส่วนที่ทำงานดี: การ์ด "สินค้าคงเหลือน้อย" ที่หน้าแรกกับปุ่มกระดิ่ง "สินค้าใกล้หมด" บนแถบเมนูบนสุด บอกตัวเลขตรงกันทั้งสองที่ (0 รายการ) และช่องค้นหาสินค้าในหน้าสินค้าคงคลังก็หาชื่อ "mozzarella whole milk" เจอทันทีตั้งแต่ครั้งแรก ไม่ต้องเดาชื่อไทย/อังกฤษเลย ใช้งานง่ายดี
- สังเกตว่าในตารางสินค้าคงคลังทั้งหมด (ลองไล่ดูทั้งหมวด Cheese & Dairy และ Meat & Seafood) คอลัมน์ "จุดสั่งซื้อ" ของทุกตัวเป็น 0 หมดเลย ไม่ใช่แค่ตัวมอสซาเรลล่า แปลว่าฟีเจอร์ "สินค้าใกล้หมด" ที่บอกว่า 0 รายการตอนนี้ อาจจะไม่ได้แปลว่าของไม่ขาด แต่เป็นเพราะยังไม่มีใครตั้งเกณฑ์ขั้นต่ำให้สินค้าตัวไหนเลยสักตัวในระบบ ก็เลยไม่มีอะไรจะ "ต่ำกว่าขั้นต่ำ" ได้ อันนี้ไม่ได้นับเป็นจุดติดของตัวเอง เพราะหน้าจอบอกข้อมูลตรงตามที่มีจริง แค่บันทึกไว้เผื่อมีประโยชน์
- ระวังไม่สับสนระหว่าง "สินค้าหมด" 286 รายการ (99.3%) กับ "สินค้าใกล้หมด" 0 รายการ — สองอันนี้คนละความหมาย ตัวที่ "หมด" ส่วนใหญ่คือของที่ยังไม่เคยรับเข้าคลังนี้เลยในเดโม ไม่ใช่ของที่เคยมีแล้วร่อยหรอลงมา เลยไม่ได้สรุปว่าระบบนับจำนวนผิด
