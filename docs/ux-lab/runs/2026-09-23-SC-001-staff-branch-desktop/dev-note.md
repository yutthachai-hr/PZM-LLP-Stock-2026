## ต้นเหตุจริงของข้อ 2–4

`resetDemoData()` โหลดสินค้ากับคลังให้ แต่**ไม่เคยสร้างผู้ขายเลย** ของจริงมีผู้ขายอยู่ราว 103 ราย
เพราะเจ้าของรันตัวนำเข้าที่อ่านชื่อผู้ขายจากวงเล็บในชื่อสินค้า (`ROCKET SALAD (ACK)` → ผู้ขาย `ACK`)
เดโมไม่เคยรันขั้นนั้น ทุกหน้าที่เกี่ยวกับการสั่งซื้อจึงตันที่ dropdown ว่าง

นี่ไม่ใช่ข้อบกพร่องของแอป — เป็นสภาพของระบบในวันแรกก่อนมีใครใส่ข้อมูลผู้ขาย
และไม่ใช่สภาพที่พนักงานเจอหน้างาน

**แก้แล้ว**: `resetDemoData()` เรียก `buildSupplierProposal` + `applySupplierProposal` ต่อจากการโหลดแคตตาล็อก
เหมือนที่ของจริงทำ ตอนนี้เดโมมีผู้ขาย 84 รายสำหรับ Pizza Mania และ 49 รายสำหรับ Le Lapin พร้อมผูกสินค้าให้แล้ว

ยืนยันหลังแก้: ค้น `ROCKET` → ขึ้น 4 รายการพร้อมคอลัมน์ผู้ขาย (ACK / KIN-D / SIMMUMMANG / YC)
เลือกแล้วช่องผู้ขายถูกเติมให้เป็น **"ACK (ผู้ขายประจำ)"** อัตโนมัติ ตรงกับที่หน้าจอสัญญาไว้ว่า "ระบบใส่ผู้ขายให้"

## ข้อ 1 ทำซ้ำได้จริง

พิมพ์ `ร็อกเก็ต` ในช่อง "ค้นหาชื่อสินค้า / รหัสสินค้า" ของหน้าสร้างใบขอซื้อ → **"ไม่พบสินค้าที่ตรงกัน"**
พิมพ์ `ROCKET` → เจอครบ 4 รายการ ยืนยันหลังจากสนามซ้อมมีข้อมูลครบแล้ว จึงไม่ใช่ผลพวงของข้อ 2

## ที่ต้องทำต่อ

run นี้เก็บไว้เป็นหลักฐานว่าสนามซ้อมเคยขาดอะไร แต่**ใช้เป็นตัวเลขวัด UX ไม่ได้**
เพราะ agent ไปไม่ถึงตัวงานจริงเลย ต้องรัน SC-001 ใหม่บนสนามซ้อมที่มีผู้ขายแล้ว
