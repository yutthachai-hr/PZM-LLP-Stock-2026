## ข้อ 2 — อ่านแถวจริงจากตารางแล้วตรงตามที่รายงานทุกประการ

```
ADJ-00001 | MOZZARELLA WHOLE MILK 2.72*8 (FOODGALLERY) ปรับตามการนับ | ปรับ    | −1 KG
CS-00001  | MOZZARELLA WHOLE MILK 2.72*8 (FOODGALLERY)               | เบิกใช้ | −2 KG
RC-00001  | MOZZARELLA WHOLE MILK 2.72*8 (FOODGALLERY)               | รับเข้า | +10 KG
```

มีเพียงแถว `ADJ` เท่านั้นที่มีข้อความต่อท้ายชื่อสินค้า

แต่ทั้ง `CS-00001` และ `RC-00001` **มีหมายเหตุอยู่จริง** — "ครัวสาขาสารสิน" และ "เลขบิล INV-2026-0912"
ตามลำดับ ตารางไม่ได้วาดมันออกมา

สิ่งที่แสดงอยู่คือ *เหตุผล* ของการปรับสต๊อก ไม่ใช่ *หมายเหตุ* จึงไม่ใช่เรื่องเดียวกัน
และหมายเหตุคือที่เดียวที่บอกว่าของไปไหน หรือมาจากบิลไหน

เทียบกับหน้ารับสินค้าเข้าซึ่งแสดง "· เลขบิล INV-2026-0912" ต่อท้ายรายการของวันนี้อยู่แล้ว —
**ตารางประวัติเป็นฝ่ายที่แสดงน้อยกว่า** ทั้งที่เป็นหน้าที่คนมาตามเรื่อง

## ข้อ 1 — รอบที่สามแล้ว

`SC-001` (ข้อสังเกต) · `SC-005` (จุดที่ติด) · `SC-007` (จุดที่ติด)
สาม agent อิสระ สามงานที่ต่างกันสิ้นเชิง ตอบสนองเหมือนกันคือกดแล้วเจอฟอร์มแก้ไขแล้วถอยออกมา

รอบนี้เพิ่มหลักฐานใหม่: หัวหน้ากดทั้ง**ชื่อสินค้า**และ**ไอคอนรูปสินค้า** ได้ผลเดียวกัน
และในฟอร์มนั้น**ไม่มีลิงก์ไปประวัติเลย** จึงไม่มีทางออกจากทางตันนั้นนอกจากปิดแล้วเดาใหม่

หัวหน้าต้องไปเจอเมนู "ประวัติ/Stock Card" เอง และบันทึกว่า *"ไม่ได้อยู่ติดกับหน้าสินค้าคงคลังเลย
คนที่ไม่คุ้นเมนูอาจไม่นึกถึงว่าต้องไปที่นั่น"*

น่าสังเกตว่าไม่มี agent ตัวไหนเจอหน้า Stock Card รายสินค้าที่ `/products/:id/card` เลยสักตัว
ทั้งที่เป็นหน้าที่ตอบคำถามของพวกเขาตรงที่สุด — มันอยู่หลังเมนู ⋮ ท้ายแถว

## ที่ agent ตั้งข้อสังเกตแล้วเราตรวจต่อ

*"กด แก้ไข ที่แถว ADJ-00001 แล้วช่องหมายเหตุว่างเปล่า ทั้งที่ในตารางมีข้อความ ปรับตามการนับ"*

ถูกต้อง และอธิบายได้: "ปรับตามการนับ" เป็น**เหตุผล** (ค่าที่เลือกจากรายการ) ไม่ใช่**หมายเหตุ** (ข้อความอิสระ)
รายการนั้นไม่มีหมายเหตุจริง ๆ จึงว่าง — ระบบไม่ได้ผิด แต่การที่สองอย่างนี้แสดงที่เดียวกันในตาราง
โดยไม่มีป้ายแยก ทำให้เข้าใจว่าเป็นอย่างเดียวกัน ข้อนี้รวมอยู่ใน `UX-0012` แล้ว

## ที่ agent ทำได้ดีและควรบันทึกไว้

รอบนี้ agent **ไม่พลาดกับดักของรอบก่อน**: เคลียร์ช่องค้นหาก่อนพิมพ์ และตรวจว่ายอด 7 KG
กับยอดที่คำนวณจากประวัติเป็นคลังเดียวกันก่อนสรุป — คำเตือนที่ใส่เพิ่มในคำสั่งได้ผลจริง
