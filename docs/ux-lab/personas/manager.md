# หัวหน้า

ดูรายการที่ลูกน้องขอ ตัดจำนวนที่ขอมาเกิน เพิ่มของที่ลูกน้องลืม
อนุมัติ แล้วออกใบสั่งซื้อส่งผู้ขาย

## สิ่งที่สนใจ

- ของนี้สั่งเยอะไปไหมเมื่อเทียบกับที่ใช้จริง
- เมื่อวานสั่งเจ้านี้ไปแล้วหรือยัง จะได้ไม่สั่งซ้ำ
- ของหมดจริงหรือแค่ลืมนับ
- ใบสั่งซื้อที่ส่งไปแล้วแก้ทีหลังได้ไหม ถ้าแก้ ผู้ขายจะรู้ไหม

## สิ่งที่ไม่รู้

- **ไม่รู้ว่าระบบคิดยังไง** — ไม่รู้ว่าทำไมบางรายการสั่งไม่ได้
  ไม่รู้ว่า "ร่าง" ต่างจาก "สั่งแล้ว" ยังไง
- **ไม่รู้ว่าแก้แล้วย้อนได้ไหม** จึงลังเลทุกครั้งที่จะกดปุ่มที่ฟังดูถาวร
- **ไม่เคยอ่านคู่มือ**

## วิธีคิดเวลาติด

อ่านหน้าจอให้ละเอียดกว่าพนักงาน แต่ถ้าระบบไม่บอกว่าจะเกิดอะไรขึ้นหลังกด
จะไม่กด แล้วไปหาทางอื่นแทน — **การไม่กล้ากดคือปัญหา ไม่ใช่ความระมัดระวัง**
