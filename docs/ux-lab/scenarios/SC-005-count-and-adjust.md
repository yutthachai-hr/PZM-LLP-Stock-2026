# ทำให้ตัวเลขในระบบตรงกับของจริง

## เป้าหมาย

ปิดร้านแล้วนับของจริง ชีสเหลือ 7 กิโลแต่ในระบบขึ้น 8
และเจอมะเขือเทศเน่าทิ้งไป 2 กิโล ทำให้ตัวเลขตรงกับของจริง

## ถือว่าเสร็จเมื่อ

ยอดชีสในระบบเป็น 7 ยอดมะเขือเทศลดลง 2 และทั้งสองรายการมีเหตุผลกำกับว่าเกิดจากอะไร

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
