# ตั้งงานนับสต๊อกสิ้นเดือน

## เป้าหมาย

ตั้งให้มีการนับสต๊อกใหญ่วันสิ้นเดือน
มอบหมายให้พนักงานสาขาทุกคน

## ถือว่าเสร็จเมื่อ

มีงานอยู่ในปฏิทินที่วันสิ้นเดือน และมอบหมายให้ทุกคนแล้ว

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
