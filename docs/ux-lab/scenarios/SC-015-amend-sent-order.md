# แก้ใบสั่งซื้อที่ส่งไปแล้ว

## เป้าหมาย

ใบสั่งซื้อที่ส่งไปเมื่อเช้า ผู้ขายบอกว่าของหมด ต้องลดจำนวนลงครึ่งหนึ่ง
แก้แล้วบอกผู้ขายใหม่

## ถือว่าเสร็จเมื่อ

ใบสั่งซื้อมีจำนวนใหม่ ยังเป็นใบเดิมไม่ใช่ใบใหม่ และรู้ว่าต้องส่งให้ผู้ขายอีกครั้ง

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
