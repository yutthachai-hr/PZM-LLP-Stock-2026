# เบิกของเข้าครัว และส่งของไปอีกสาขา

## เป้าหมาย

เบิกชีสมอสซาเรลล่า 2 กิโลเข้าครัวสาขาสารสิน
แล้วส่งแป้ง 1 ถุงไปให้สาขาอ่อนนุชที่ของขาด

## ถือว่าเสร็จเมื่อ

ชีสที่สารสินลดลง 2 กิโล และแป้งย้ายจากที่เดิมไปอยู่ที่อ่อนนุช 1 ถุง

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
