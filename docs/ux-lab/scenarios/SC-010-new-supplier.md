# เพิ่มผู้ขายเจ้าใหม่ แล้วผูกของให้

## เป้าหมาย

มีผู้ขายผักเจ้าใหม่ชื่อ "สวนผักลุงมี" เบอร์ 081-234-5678
เพิ่มเข้าระบบแล้วผูกผักร็อกเก็ตให้เจ้านี้

## ถือว่าเสร็จเมื่อ

ผู้ขายรายใหม่อยู่ในระบบพร้อมเบอร์โทร และผักร็อกเก็ตขึ้นเป็นสินค้าของเจ้านี้

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
