# ตามหาว่าของหายไปตอนไหน

## เป้าหมาย

ชีสหายไป 3 กิโลโดยไม่รู้สาเหตุ
ตามหาว่าหายตอนไหน ใครเป็นคนทำรายการ

## ถือว่าเสร็จเมื่อ

บอกได้ว่ารายการไหนทำให้ยอดลดลง วันไหน และใครเป็นคนทำ

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
