# เอายอดปิดสิ้นเดือนจาก Excel เข้าระบบ

## เป้าหมาย

มีไฟล์ Excel ยอดปิดสิ้นเดือนจากสาขา
อยากเอาตัวเลขเข้าระบบทีเดียวทั้งไฟล์

## ถือว่าเสร็จเมื่อ

ยอดคงเหลือในระบบตรงกับตัวเลขในไฟล์ และรู้ว่าแถวไหนเข้าไม่ได้เพราะอะไร

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
