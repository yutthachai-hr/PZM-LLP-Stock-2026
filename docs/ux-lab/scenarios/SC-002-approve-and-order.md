# ตรวจของที่ลูกน้องขอ แล้วสั่งจริง

## เป้าหมาย

ลูกน้องขอผักมา ร็อกเก็ตขอมา 3 กิโลแต่ให้แค่ 2 พอ และลืมขอโค้กซีโร่ 5 แพ็ค เพิ่มให้ด้วย
แล้วอนุมัติและออกใบสั่งซื้อส่งผู้ขาย สุดท้ายเอารายการออกเป็น Excel

## ถือว่าเสร็จเมื่อ

ใบขอซื้อถูกอนุมัติโดยจำนวนร็อกเก็ตเป็น 2 มีโค้กซีโร่เพิ่มเข้ามา มีใบสั่งซื้อออกให้ผู้ขาย และได้ไฟล์ Excel

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
