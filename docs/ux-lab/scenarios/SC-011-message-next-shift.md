# ฝากข้อความถึงกะบ่าย

## เป้าหมาย

ฝากบอกกะบ่ายว่าของ FOODGALLERY จะมาบ่ายนี้ ให้รอรับด้วย

## ถือว่าเสร็จเมื่อ

คนที่เข้ากะบ่ายเปิดระบบแล้วจะเห็นข้อความนี้

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
