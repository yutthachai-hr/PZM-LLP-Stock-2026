# สั่งของประจำสัปดาห์จากไฟล์ Excel

## เป้าหมาย

มีไฟล์ Excel รายการที่ต้องสั่งประจำสัปดาห์
อยากให้ระบบแยกใบสั่งซื้อตามผู้ขายให้เอง แล้วส่งให้ผู้ขายทาง LINE

## ถือว่าเสร็จเมื่อ

มีใบสั่งซื้อแยกตามผู้ขาย และรู้ว่าแถวไหนระบบไม่แน่ใจจนต้องให้คนเลือกเอง

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
