# เพิ่มหน่วยที่เลือกได้ตอนคีย์

## เป้าหมาย

ตอนคีย์รับของ หน่วยที่เลือกได้ไม่มี "ถุง" อยากเพิ่มเข้าไป

## ถือว่าเสร็จเมื่อ

มี "ถุง" ให้เลือกตอนคีย์ — หรือรู้ชัดว่าตัวเองทำไม่ได้และต้องไปบอกใคร

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
