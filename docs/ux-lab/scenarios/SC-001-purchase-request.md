# ขอให้สั่งผักเพิ่ม

## เป้าหมาย

พรุ่งนี้ผักจะหมด อยากให้สั่งเพิ่ม — ผักร็อกเก็ต 3 กิโล โอ๊คแดง 5 กิโล
และโค้กกระป๋อง 5 แพ็ค ส่งให้หัวหน้าดูให้เรียบร้อย

## ถือว่าเสร็จเมื่อ

มีใบขอสั่งซื้อที่หัวหน้าเห็นได้ มีของครบสามรายการ จำนวนตรงตามที่ตั้งใจ

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
