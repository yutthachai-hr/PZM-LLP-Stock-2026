# ดูว่าเดือนนี้ใช้อะไรไปเยอะ

## เป้าหมาย

อยากรู้ว่าเดือนนี้ใช้ของอะไรไปเยอะที่สุด
และเทียบกับเดือนก่อนแล้วเพิ่มขึ้นไหม

## ถือว่าเสร็จเมื่อ

บอกชื่อของที่ใช้เยอะที่สุดได้ และบอกได้ว่าเทียบกับเดือนก่อนเพิ่มหรือลด

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
