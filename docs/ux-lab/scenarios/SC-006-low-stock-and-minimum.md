# ดูว่าอะไรใกล้หมด แล้วตั้งให้เตือนล่วงหน้า

## เป้าหมาย

อยากรู้ว่าตอนนี้ของอะไรใกล้หมดบ้าง
แล้วตั้งจุดสั่งซื้อของชีสไว้ที่ 5 กิโล จะได้เตือนก่อน

## ถือว่าเสร็จเมื่อ

รู้รายชื่อของที่ใกล้หมด และชีสมีจุดสั่งซื้อเป็น 5 แล้ว

## ห้าม

ห้ามบอกทางในไฟล์นี้ ถ้า agent หาไม่เจอ นั่นคือผลการทดสอบ ไม่ใช่ความผิดของ agent
