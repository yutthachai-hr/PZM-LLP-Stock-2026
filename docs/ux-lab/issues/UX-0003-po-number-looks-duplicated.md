# ใบสั่งซื้อคนละผู้ขายขึ้นเลขเดียวกัน หน้าจอไม่บอกว่าเลขรันแยกตามผู้ขาย

## อาการ

แปลงใบขอซื้อหนึ่งใบที่มีสองผู้ขายเป็นใบสั่งซื้อ ได้ใบสั่งซื้อสองใบ แล้วตารางหน้า `/orders` ขึ้นสองแถวติดกัน:

```
AC   ACK            PO-00001   23/09/2569   2 รายการ   สั่งแล้ว
TH   THAINAMTHIP    PO-00001   23/09/2569   2 รายการ   สั่งแล้ว
```

เลขเหมือนกันทุกตัวอักษร ไม่มีข้อความใดบนหน้าจออธิบายว่าทำไม

## ที่คาดว่าจะเป็น

เลขเอกสารไม่ซ้ำกัน หรือถ้าซ้ำได้ หน้าจอต้องบอกว่าทำไมถึงซ้ำได้

## ระบบทำถูกแล้ว — อย่าแก้ที่การออกเลข

**เลข PO รันแยกตามผู้ขายเป็นการตัดสินใจของเจ้าของเมื่อ 14 ก.ย. 2569** (`counters/purchaseOrder__<supplierId>`)
ผู้ขายแต่ละเจ้าจึงเห็นเลขของตัวเองเรียง 1, 2, 3 ซึ่งเป็นสิ่งที่ผู้ขายต้องการ เลขซ้ำข้ามผู้ขายคือผลที่ตั้งใจ

**ห้ามแก้ด้วยการเปลี่ยนวิธีออกเลขเด็ดขาด** — ขัดกับการตัดสินใจของเจ้าของ ทำให้ใบที่พิมพ์ส่งผู้ขายไปแล้วเพี้ยน
และเป็นงานระดับ `HIGH` ที่ต้องให้เจ้าของอนุมัติ ทางแก้ที่รับได้อยู่ที่การแสดงผลเท่านั้น

## ทำซ้ำได้โดย

1. มีใบขอซื้อที่มีสินค้าจากสองผู้ขายขึ้นไป แล้วอนุมัติและกด "สร้างใบสั่งซื้อ"
2. ไปหน้า "สั่งซื้อ"

จะเห็นสองแถวเลขเดียวกัน ต่างกันแค่ชื่อผู้ขายที่บรรทัดบนของเลข

## ทำไมจึงจัดเป็น UX_FRICTION / severity minor / risk LOW

**ไม่ใช่ BUG** — ระบบออกเลขตามกติกาที่ถูกกำหนดไว้อย่างจงใจ

**ไม่ใช่ BUSINESS_RULE** — กติกาไม่ได้ผิด ผู้ขายต้องการเลขเรียงของตัวเองจริง ๆ

**ไม่ใช่ TRAINING_ISSUE** แม้จะแก้ด้วยการบอกให้รู้ได้ เพราะสิ่งที่ขาดอยู่บนหน้าจอ ไม่ใช่ในหัวคน
หน้าจอที่วางเลขซ้ำกันสองบรรทัดโดยไม่มีคำอธิบาย คือหน้าจอที่ทำให้เข้าใจผิดได้เอง

**severity minor** เพราะไม่ได้ขวางงาน หัวหน้าสังเกตเห็นแล้วทำงานต่อได้

**risk LOW** เพราะทางแก้ที่ยอมรับได้คือการแสดงผลล้วน ๆ — เช่น วางรหัสผู้ขายไว้กับเลข
หรือใส่คำอธิบายสั้น ๆ ว่าเลขรันแยกตามผู้ขาย **ถ้าทางแก้ไหนแตะการออกเลข ต้องยกเป็น HIGH ทันที**
