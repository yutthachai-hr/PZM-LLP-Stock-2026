# รับเข้าหลายบิลในครั้งเดียว — Design

วันที่: 24 ก.ย. 2569 · สถานะ: **อนุมัติแล้ว (เจ้าของเลือกแบบ A "แยกกล่องต่อบิล" และอนุมัติดีไซน์ใน chat)**

## ปัญหา

คลังรับของวันละหลายเจ้า หลายบิล (owner: *"เรารับเข้า 1 วัน หลายรายการ หลายซับพลายเออ"*) แต่หน้า
รับสินค้าเข้ามีช่อง "หมายเหตุ / เลขบิลส่งของ (Supplier)" ช่องเดียวต่อการบันทึกหนึ่งครั้ง — รับ 5 บิลต้อง
กรอก-บันทึก-ล้าง 5 รอบ ตรวจ git แล้ว หน้านี้เป็นแบบบิลเดียวมาตั้งแต่ commit แรก (`08e0dbd`) ไม่เคยมีแบบหลายบิล

## ดีไซน์ (แบบ A)

- การ์ด **ข้อมูลการรับ** ใช้ร่วมทุกบิล: คลังปลายทาง · วันที่รับ · ผู้รับเข้า (อัตโนมัติ) — ช่องเลขบิลย้ายออก
- การ์ด **บิล N** ต่อบิล: `เลขบิล / Supplier *` (คำแนะนำ/ตัวอย่างเดิม) + `LineBuilder` ของบิลนั้น (ค้นหา, สแกน,
  หน่วย, หมายเหตุรายแถว — เหมือนเดิม) + ปุ่มลบบิล (มีรายการ → ถามยืนยัน; เหลือบิลเดียว → ไม่มีปุ่ม)
- ปุ่ม **+ เพิ่มบิล** ใต้การ์ดสุดท้าย → เพิ่มบิลว่าง โฟกัสช่องเลขบิลของบิลใหม่
- ปุ่มบันทึก: `บันทึกรับเข้า {bills} บิล ({n} รายการ)`

### บันทึก
1. ตรวจทุกบิลก่อนเขียน (`planBills`, pure): ข้ามบิลว่างล้วน · บิลมีรายการแต่ไม่มีเลขบิล → error ระบุบิล ·
   มีเลขบิลแต่ไม่มีรายการ → error ระบุบิล · จำนวน ≤ 0 → error ระบุบิล · ไม่มีรายการเลยทั้งหน้า → error เดิม
2. บันทึก **ทีละบิล** ด้วย `receiveStock` เดิม → **1 บิล = RC- 1 ใบ** (note = เลขบิล) — ข้อมูล/ประวัติ/Stock Card เหมือนเดิม
3. บิลที่บันทึกผ่านถูกเอาออกจากฟอร์มทันที → ถ้าบิลที่ k ล้ม บิลก่อนหน้าไม่ถูกบันทึกซ้ำตอนกดใหม่; toast บอกบิลที่ล้ม
4. สำเร็จทั้งหมด → toast `รับเข้าแล้ว {n} บิล: RC-…, RC-…` → ฟอร์มกลับเป็นบิลว่าง 1 ใบ โฟกัสช่องเลขบิล
- สินค้าเดียวกันอยู่ได้หลายบิล (ในบิลเดียว LineBuilder กันซ้ำเหมือนเดิม)

### ร่าง
`useDraft('receive', { toLocationId, dateStr, bills })` · ร่างรูปแบบเก่า `{ note, lines }` → ย้ายเป็นบิลที่ 1 (`restoreBills`, pure)

## ไม่แตะ
ฐานข้อมูล, `firestore.rules`, `services/stock.ts`, "ตรวจรับของ" จากใบสั่งซื้อ
