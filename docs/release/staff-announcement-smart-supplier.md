# ประกาศพนักงาน: การรับสินค้าแบบใหม่ — ระบบช่วยเลือกผู้ขาย

(ใช้เมื่อเจ้าของอนุมัติ PR #4 แล้วเท่านั้น)

**เริ่มใช้:** วันที่ ___

**มีอะไรเปลี่ยน:**

1. **รับตามใบสั่งซื้อ (PO):** ผู้ขายถูกล็อกตาม PO เหมือนเดิม และขึ้นป้าย "จาก PO-xxxxx"
2. **รับนอกใบสั่งซื้อ:** เมื่อเลือกสินค้าแล้ว ถ้าสินค้านั้นผูกกับผู้ขายรายเดียว ระบบจะ **ใส่ผู้ขายให้เอง** พร้อมข้อความ "เลือกให้อัตโนมัติจากสินค้าที่เลือก"
   - **ตรวจกับบิลจริงทุกครั้ง** ถ้าไม่ตรง เปลี่ยนเองได้ทันที และระบบจะไม่เปลี่ยนกลับ
3. **ถ้าสินค้าในใบเดียวกันมาจากผู้ขายต่างกัน:** ระบบ **จะไม่สลับผู้ขายให้เอง** แต่จะแจ้งเตือน ให้เลือกอย่างใดอย่างหนึ่ง
   - "ลบรายการนั้น"
   - "แยกไปใบรับถัดไป"
4. **ถ้าสินค้าซื้อได้จากหลายผู้ขาย:** ระบบจะ **แนะนำ** ให้กดเลือกเอง ไม่เลือกแทน

**ข้อควรจำ:**

- **ชื่อในวงเล็บท้ายชื่อสินค้า เช่น "(LARDER)" ไม่ได้ใช้ตัดสินผู้ขาย** ระบบดูจากข้อมูลผู้ขายที่ผูกไว้ในหน้าสินค้าเท่านั้น
- **ถ้าเห็นว่าสินค้าผูกผู้ขายผิด** ให้แจ้งหัวหน้าหรือผู้ดูแลให้แก้ที่หน้าสินค้า อย่าแก้ด้วยการเลือกผู้ขายผิดในใบรับ
- ใบรับที่บันทึกแล้ว สต๊อก และ Stock Card ทำงานเหมือนเดิมทุกอย่าง
